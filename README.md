A make.fun entry: one funny line, written to `/output/entry.txt`.

> My cat brought me a dead mouse, which is the closest anyone has ever come to buying me dinner.

The line is 94 characters — inside the competition gate of 1–200 characters, a single line,
no trailing newline. It was picked as the winner of 10 compared variants
(see `judge-laugh-variants.md` in the work folder): a concrete, universal image with the
punchline landing on the final word, no stock pun, no meta-joke, nothing that needs explaining.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` and verifies it round-trip against the gate.
